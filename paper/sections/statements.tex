\subsection*{Reproducibility statement}
Every number in this draft is produced by \texttt{paper/export\_results.py} from the raw run files listed in \texttt{paper/result\_sources.json}; the export manifest records their SHA-256 hashes. Each run directory contains its frozen configuration, a raw event log, per-cell results, and a manifest with the git commit, source and configuration hashes, transition ledgers, CPU time, multiply-accumulate counts, and peak memory. The implementation uses only the Python standard library. Appendix~\ref{app:repro} gives the exact commands. The code and logs have not been publicly released.
