None of the following has been run. No result of any of them appears in this draft.
\begin{itemize}
  \item \textbf{Diagnosing the learned-encoder floor.} Three kinds of run could separate the explanations listed as conjectures in Section~\ref{sec:discussion}. The first would pretrain for longer or with the pre-registered learning-rate grid. The second would vary the prediction horizon relative to corridor length. The third would give the readout head more capacity or a direct probe-based head. None was run. Any such run would be exploratory, would need new seeds, and must not be presented as a confirmation. Changing the environment to make an effect appear after seeing this negative result is excluded by our protocol.
  \item \textbf{Pre-registered pilot.} Ten seeds in both maze variants with a paired bootstrap analysis. It was not approved and not run. Seeds 1--3 of that plan have now been used by the 2$\times$2 study and are development data.
  \item \textbf{Asymmetric control variant.} In this variant, action-marginal futures also carry the clue. It was not run.
  \item \textbf{Unstandardized readout.} The head without feature standardization, as in the original pilot plan. It was not run.
  \item \textbf{External comparisons.} An action-conditioned future-prediction method in the style of \citet{kwon2024future}, recurrent world models, and recurrent model-free agents. None was run.
  \item \textbf{Other environments.} Longer corridors, other task families, and partially observable continuous control. None was run, and none is planned without a positive result here.
\end{itemize}
